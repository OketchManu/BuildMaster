
🏗️ BuildMaster

BuildMaster is a mobile application designed for construction and building project management. The app helps contractors, site managers, and engineers to track construction progress, manage resources, communicate with teams, and oversee project timelines — all in one place.


---

🚀 Features

📋 Project Management – Create, view, and manage multiple construction projects.

🛠️ Task Tracking – Assign tasks, set deadlines, and monitor progress.

👷 Team Collaboration – Manage site workers, supervisors, and stakeholders.

📊 Progress Reports – View real-time updates, generate reports, and track milestones.

💰 Budgeting & Resources – Keep track of materials, costs, and resources.

🔔 Notifications – Stay updated with project changes and deadlines.

☁️ Cloud Integration – Data synced using Firebase backend for security and scalability.



---

🏁 Getting Started

These instructions will help you set up the project on your local machine for development and testing purposes.

📌 Prerequisites

Install Flutter (latest stable version).

Install Dart.

Setup Android Studio or VS Code with Flutter & Dart plugins.

A connected device or emulator for testing.


⚙️ Installation

1. Clone the repository

git clone https://github.com/OketchManu/BuildMaster.git
cd BuildMaster


2. Install dependencies

flutter pub get


3. Setup Firebase

Add your own google-services.json (Android) or GoogleService-Info.plist (iOS) in the respective directories.

Update firebase.json as required.



4. Run the app

flutter run
